# 05: 金额与基础风控规则引擎

**What to build:** 单据提交后，系统自动执行人民币含税金额交叉核验、费用标准核验、重复发票和批量付款防重规则，并输出可解释、可定位证据的风险项。

**Blocked by:** 03: 凭证上传、OCR 解析与人工校正

**Status:** ready-for-agent

- [ ] 比对单据申请金额、明细合计、关联发票价税合计和合同付款比例金额。
- [ ] 计算绝对差额、偏离比例、漏项、重复项和算术差额，金额精度为分。
- [ ] 校验合同付款比例、履约节点、累计已付金额和合同总限额。
- [ ] 校验批量付款收款账户、收款人、重复单笔金额和批次汇总差异。
- [ ] 按部门、城市等级、职级和费用类型执行差旅/招待费用标准校验。
- [ ] 跨单据按发票代码、号码、开票日期和价税合计检测重复报销。
- [ ] 每个规则结果包含输入值、计算值、阈值、规则版本、风险级别和证据引用。
- [ ] 规则异常不会阻止人工复核，但必须形成结构化风险项并参与综合风险评级。
