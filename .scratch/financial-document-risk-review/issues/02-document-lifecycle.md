# 02: 五类业务单据生命周期

**What to build:** 申请人可以创建和维护对公付款单、预付款单、批量付款单、费用报销单和差旅报销单，并按规定状态完成提交、撤回、退回、重新提交、驳回和作废。

**Blocked by:** 01: 平台基础、企业 SSO 与不可变审计

**Status:** ready-for-agent

- [ ] 五类单据均有对应的基本信息、部门、收款单位、事由和支出明细字段。
- [ ] 申请人可以创建、编辑、保存草稿和查看自己的单据。
- [ ] 支持草稿、待初审、审批中、退回待补充、已通过、已驳回和已作废等状态。
- [ ] 申请人只能在待初审前撤回；退回单据可补充后形成新版本并重新提交。
- [ ] 驳回终止当前流程；作废需要单独权限和必填原因，且不删除业务数据。
- [ ] 每次状态转移记录操作者、前后状态、原因、时间戳和版本指纹。
- [ ] 重复提交、越权编辑和无效状态转移被拒绝并产生审计事件。
