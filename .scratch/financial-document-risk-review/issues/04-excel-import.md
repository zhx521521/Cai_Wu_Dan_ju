# 04: 固定 Excel 批量导入

**What to build:** 申请人可以使用固定 Excel 模板批量创建五类业务单据，并获得逐行、逐字段的校验结果；成功导入的数据遵循与页面创建相同的生命周期和权限规则。

**Blocked by:** 02: 五类业务单据生命周期

**Status:** ready-for-agent

- [ ] 提供包含五类单据必填字段、金额、部门、收款单位和明细的固定 Excel 模板。
- [ ] 导入前校验单据类型、必填项、人民币含税金额、日期、金额精度和枚举值。
- [ ] 返回错误行、错误字段和可操作的修正提示，不因单行错误静默丢弃整批数据。
- [ ] 成功行创建为草稿并可继续上传凭证和提交审核。
- [ ] 重复导入可识别业务唯一键或重复内容，并要求用户确认处理方式。
- [ ] 导入文件、操作者、成功/失败数量和错误摘要写入审计记录。
