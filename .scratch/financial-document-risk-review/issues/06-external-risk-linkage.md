# 06: 外部征信与市场价格风险联动

**What to build:** 系统使用真实供应商工商征信和市场公允价服务补充风险判断，并对无数据、服务失败和过期数据做出明确区分。

**Blocked by:** 05: 金额与基础风控规则引擎

**Status:** ready-for-agent

- [ ] 通过可配置适配器查询供应商存续状态、经营异常、严重违法失信和近期账号变更。
- [ ] 按物资/服务名称、规格、地区和日期查询市场基准价格区间、样本数、来源和有效期。
- [ ] 市场价格偏离配置容差时生成溢价风险；无可靠基准时标记无法评估而非判定违规。
- [ ] 外部服务返回成功、无数据、可重试失败和不可重试失败四种可区分结果。
- [ ] 失败或超时不被错误归类为无风险；系统展示重试状态和人工处置入口。
- [ ] 保存查询时间、服务版本、数据来源和请求摘要，供工作台和报告引用。
- [ ] 征信和市场价格结果参与单项及整体风险等级计算，并可被人工确认或忽略。
