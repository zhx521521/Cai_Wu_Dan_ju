# 03: 凭证上传、OCR 解析与人工校正

**What to build:** 申请人可以上传凭证并获得真实 OCR/多模态服务的结构化结果；系统展示原文坐标和置信度，并在关键字段低置信度或解析失败时阻止提交，直到人工校正完成。

**Blocked by:** 02: 五类业务单据生命周期

**Status:** ready-for-agent

- [ ] 支持 PDF、PNG、JPG 附件，单个附件不超过 20 MB、50 页，并对超限文件给出明确错误。
- [ ] 通过可配置适配器调用真实 OCR/多模态服务，记录服务版本、解析时间和请求摘要。
- [ ] 提取发票代码、发票号码、价税合计、税额、开票日期、购销方、合同付款比例和付款条件等关键字段。
- [ ] 每个字段返回规范化值、原始文本、页码、坐标、置信度和凭证引用。
- [ ] 原文预览与字段列表联动，高亮字段对应的证据坐标。
- [ ] 关键字段低于阈值、冲突或解析失败时进入待申请人确认并阻止提交。
- [ ] 用户可以在原文定位处修正字段；修正前后值、原因和操作者进入审计记录。
- [ ] 外部服务超时、限流、可重试失败和不可重试失败均有可见状态，不得默认为无风险。
