# 07: 动态审批流与三栏审核工作台

**What to build:** 财务人员可以在三栏工作台中完成单据、凭证和风险的联动复核；系统按部门、单据类型、金额区间和风险等级匹配审批节点，并支持完整的人工处置和流转动作。

**Blocked by:** 05: 金额与基础风控规则引擎；06: 外部征信与市场价格风险联动

**Status:** ready-for-agent

- [ ] 管理员可配置部门、单据类型、金额区间和风险等级到审批节点的映射。
- [ ] 提交时生成审批实例并保存命中的规则版本和节点快照；无匹配时进入安全默认流程。
- [ ] 工作台左侧展示结构化单据，中部展示凭证原文/OCR 证据，右侧展示风险诊断和操作区。
- [ ] 点击风险项可联动高亮原文坐标，并显示规则依据、阈值、数据源和当前状态。
- [ ] 支持将风险项标记为确认为异常或忽略提示，并记录必填复核意见。
- [ ] 支持通过、退回补充材料、驳回、转交和加签；退回/驳回等操作必须填写原因。
- [ ] 审批按钮按角色、当前节点和单据状态动态控制，重复点击不会产生重复审批事件。
- [ ] 所有人工结论与系统原始风险并列保存，不覆盖原始规则结果。
