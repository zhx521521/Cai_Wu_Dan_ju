# 09: 端到端验收场景与演示链路

**What to build:** 使用固定验收数据完成至少一个可重复的端到端业务场景，并验证真实外部服务、人工复核、动态审批、报告归档和失败处理能够共同工作。

**Blocked by:** 04: 固定 Excel 批量导入；07: 动态审批流与三栏审核工作台；08: 报告中心、审计追溯与管理视图

**Status:** ready-for-agent

- [ ] 使用用户提供的费用标准、市场基准、供应商数据和示例凭证建立固定验收数据集。
- [ ] 完成“大额技术服务费对公付款”或等价典型场景：创建、上传合同/发票、解析、核验、发现合同付款比例风险、人工复核、驳回或退回、报告归档。
- [ ] 验证五类单据至少各完成一次创建和生命周期操作。
- [ ] 验证 PDF/PNG/JPG、20 MB/50 页边界、低置信度拦截和人工校正放行。
- [ ] 验证金额交叉核对、费用超标、重复发票、市场价格偏离和供应商风险结果。
- [ ] 验证动态审批在不同部门、金额区间和风险等级下匹配正确节点。
- [ ] 验证外部适配器超时、无数据、可重试失败和不可重试失败不会产生错误的无风险结论。
- [ ] 验证重复提交、并发编辑、审批重复点击和网络重试不会生成重复审批事件。
- [ ] 验证最终报告可导出、证据链可定位、审计记录永久可追溯且不可修改。
