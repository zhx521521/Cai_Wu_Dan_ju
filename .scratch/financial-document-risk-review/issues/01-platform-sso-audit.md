# 01: 平台基础、企业 SSO 与不可变审计

**What to build:** 用户可以通过企业 SSO 登录并映射系统角色，创建最小单据草稿；系统为关键操作追加不可变审计事件，形成后续功能共用的身份、权限和追溯基础。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 支持企业 SSO 登录，并将用户映射为申请人、财务初审员、审批人、系统管理员或审计只读用户。
- [ ] 未授权用户不能访问业务数据或执行写操作；服务端执行资源归属和权限校验。
- [ ] 用户可以创建一个最小草稿并查看创建结果。
- [ ] 登录、创建、修改和权限拒绝事件均追加写入审计记录。
- [ ] 审计记录不可修改、不可删除，包含操作者、动作、对象、时间戳和结果。
- [ ] 提供适合后续端到端测试使用的登录和审计验证入口。
